# Snake Game

A classic Snake game built with Python and Pygame.

## Requirements

- Python 3.7+
- Pygame

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Lucaschenthebest/snake-game.git
cd snake-game
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## How to Run

```bash
python snake_game.py
```

## Game Controls

- **Arrow Keys**: Move the snake (Up, Down, Left, Right)
- **SPACE**: Restart the game when it's over

## Game Rules

- The snake starts in the center of the screen and moves continuously
- Eat the red food to grow and gain points
- Avoid hitting the walls or yourself
- Game ends when the snake collides with a wall or itself
- Press SPACE to restart and play again

## Features

- Score tracking
- Grid-based movement
- Food spawning
- Collision detection
- Game over and restart functionality
- Smooth controls

## Gameplay

- You control a snake that continuously moves
- Press arrow keys to change direction
- Eat red food squares to grow longer and increase your score
- Each food eaten gives you 10 points
- The game ends if you hit a wall or yourself
- Press SPACE to restart

Enjoy!
